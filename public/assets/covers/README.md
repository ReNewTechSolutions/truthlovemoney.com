# Editorial Cover Assets

Place final Lyon Den editorial cover artwork in this folder.

Recommended format:

- `.png` or `.jpg`
- 16:9 ratio for YouTube chapter covers
- warm ivory, creek blue, sage, and warm gold palette
- literary/book-cover style
- minimal or no faces

After adding a cover, update the matching `customCover` field in `src/App.jsx`:

```js
customCover: '/assets/covers/example-cover.png'
```
